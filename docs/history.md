# A Short History

MetaVibing originated during experiments with a more heavily governed agent workflow. Early versions of this repository — the book, the TaskFlow specimen, the first evaluation charter — were produced under that governed workflow, with explicit contracts, validators, and human approval gates on every artifact.

The alpha has since been simplified to a direct Claude Code + Git + tests workflow. That governance layer is off the critical path for MetaVibing itself; it was a useful discipline for producing early drafts honestly, not a permanent part of the product.

Historical process artifacts — decision records, run logs, provenance contracts — are not part of this repository's live tree, but remain available in Git history for anyone who wants to see exactly how each early artifact was produced.
